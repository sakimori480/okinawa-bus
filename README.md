# 沖縄バス：歩ける範囲と時刻

地図に出発地と目的地を置くと、そのまわりの歩ける範囲にあるバス停を表示し、沖縄バスの便で行く方法を探すWebアプリです。

## できること

- 出発地・目的地から歩ける範囲（歩く速さ×時間の円）にあるバス停を表示
- バス停を選ぶと、そこから出る便の時刻を表示
- 出発時刻または到着時刻を指定して、行き方を検索（乗り換え2回まで）
  - 乗り換え時間が10分以下なら注意を表示
  - 同じ便に目的地寄りのバス停からも乗れる場合はお知らせ（運賃が安くなることがあるため）
- 運賃は公開データにある空港リムジンバスのみ表示。路線バスの運賃は[バスなび沖縄](https://www.busnavi-okinawa.com/top/Transit)で調べられるよう案内

## 注意

- 沖縄バス（株）の路線だけが対象です。琉球バス交通・那覇バス・東陽バスは公開データがないため含まれていません。
- 時刻は時刻表上の予定です。遅れや運休は反映されません。
- 距離は直線での目安です。

## ファイル

- `index.html` … 画面本体
- `data/bus-data.js` … 画面が読み込むデータ（下のスクリプトで作る）
- `tools/build_data.py` … GTFS を `data/bus-data.js` に整理するスクリプト

## データの更新

OTTOP から新しい GTFS をダウンロードして解凍し、そのフォルダを指定して実行します（Python 3、追加ライブラリ不要）。

```
python tools/build_data.py "解凍したGTFSのフォルダ" data/bus-data.js
```

運行日は日付ごとに展開しているので、データの期間（今のデータは 2027/03/31 まで）を過ぎる前やダイヤ改正のときに作り直してください。
